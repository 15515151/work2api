# 用户门户与管理员

[返回项目首页](../README.md)

用户入口为 `/portal/`，管理入口为 `/admin-ui/`。同一登录界面按服务端验证的身份跳转：普通用户进入门户，管理员和超级管理员进入管理台。是否公开管理入口由部署者的反代与访问控制决定；网关不会自动改变现有入口规则。

## 用户使用流程

1. 根据站点开放方式注册或使用邀请码，登录后即可创建 API Key，账号贡献不是前置条件。
2. 在模型页查看当前可调用模型。默认开放模型、本人账号支持的模型和管理员额外授权共同决定可用范围，管理员全局禁用始终生效。
3. 新 Key 默认跟随当前权限，也可以固定模型范围。固定范围不会因后续开放新模型自动扩大，且模型失去当前授权后仍会被拒绝。固定空范围拒绝所有模型。
4. 可选择贡献本人账号。账号进入统一账号管理页，Key 进入统一 API 密钥页，管理员能看到用户归属。
5. 撤回贡献后账号仅本人可用，默认模型权限继续保留。可以重新贡献，原有停用与冷却状态不会因此清除。

每日调用和 token 预算默认不限；仍保留网关已有并发、排队和请求保护配置。

## 四渠道贡献方式

| 渠道 | 用户贡献方式 | 说明 |
|---|---|---|
| WorkBuddy / CodeBuddy | 扫码授权，选择国内或国际站点 | 保留原有区域、成本、会话粘性和故障处理 |
| 国内 Trae IDE / Work-SOLO | 网页授权，必要时手工提交回调 | 两个产品凭据独立，同一上游用户共用归属 |
| Qoder | 国内 / 国际扫码授权或个人 PAT | 用户贡献不切换管理员激活账号；并行登录任务独立 |
| OpenCode | 个人 Zen / Go API Key | 验证凭据与模型目录后添加；匿名 public 入口属于系统资源，不可贡献 |

仅接受本人账号或个人凭据。已有管理员账号或其他用户账号不能由用户自行认领；归属冲突需要管理员处理。页面与模型接口不会公开其他用户的凭据或账号标识。

## 默认开放模型

管理员在「门户管理」维护规则：

- 自动模式：以渠道明确的免费来源发现模型，并允许手工加入或排除模型。
- 手工模式：只开放手工选中的模型。
- 用户额外授权：在默认范围和本人账号之外单独增加模型权限。
- 全局禁用用户模型：对默认权限、本人模型和额外授权均生效；管理员私人 Key 继续使用自己的模型白名单。

**免费来源只用于模型授权，不是实际调用免费承诺。** 模型开放后仍按渠道现有成本、区域、粘性和故障回退策略选账号，可能消耗收费账号额度。所有有效管理员账号和在贡献状态的账号均可提供已开放模型；撤回的账号仅供本人使用。

自动发现的新模型对跟随范围 Key 生效。未知价格、参考价和偶次消费为零不能单独证明免费。Trae 当前没有经过验证的自动免费价格依据，管理员可手工开放其模型。

## 管理员身份

- 超级管理员可直接创建管理员或升级已有用户；普通管理员管理普通用户。升级身份保留账号贡献及 Key 配置。
- 管理员和超级管理员日常管理能力相同；管理员任免、停用、密码恢复与超级管理员交接由超级管理员负责。
- 新建账号或管理重置密码后先修改临时密码。身份变更、停用及改密会撤销相关登录会话。
- `ADMIN_TOKEN` 保留为恢复入口，不应向普通用户分发。敏感身份操作要求最近完成密码或恢复 Token 验证。
- 管理员会话与普通用户会话隔离。管理员身份不自动扩大其用户 Key 权限。

## 升级与旧权限

数据库 v21 停止使用共享池 / 分组进行日常授权，旧表暂留以便迁移和排查。旧的有效分组授权迁移为保留原账号范围的历史授权，不会自动扩大成整个账号池。管理员可以明确移除历史授权，再重新配置新的模型授权。

旧用户 Key 保持固定范围，管理员可以改为跟随。升级前保留完整备份；回退至旧版本需要恢复匹配的数据库与凭据，不能仅替换二进制。


## 邀请码

管理员创建邀请码时可设置使用次数（默认1次，也可明确选择不限）和有效期（默认7天，可选快捷时长、指定本地日期时间或永不过期）。生成后可编辑配置、停用和恢复，并查看分页使用记录。列表显示已用次数、剩余次数、到期时间和可用状态，支持复制邀请码及邀请链接。

次数是注册成功的总次数上限，编辑时不能低于已经使用的次数；不是每个用户的调用次数。注册与次数扣减在同一事务完成，注册失败不消耗次数。停用、过期和次数用尽只阻止后续注册，不撤销已有用户或Key。

数据库v22将旧邀请码迁移为最多1次；旧已用码保持已用，旧未用码仍可使用1次。原有到期时间保留。多人使用的邀请码不包含管理员权限或额外模型授权。

模型范围编辑支持全选当前搜索结果、取消当前结果和清空全部；搜索之外的选择保持，全选只包含当前可选目录，不会自动加入失效条目。批量选择仍需明确保存，Key跟随模式与当前模型全选快照不同。

## Key、模型与调用记录

我的密钥支持随时查看、隐藏和复制本人 Key，明文按需读取，不保存在浏览器持久存储中。旧版未保存密文或主密钥无法验证时无法恢复，需要检查备份或重新创建 Key。

可用模型与管理台共用参数卡，展示上游确认的能力、思考档位及渠道价格说明。成本系数仅适用于对应渠道，未知价格不视为免费；管理员测试和账号详情不会开放到门户。

用量页面提供本人调用的分页日志，按网关请求标识归并重试。详情展示请求与实际模型、协议、Token/缓存读取、结束原因、排队和账号等待、HTTP 状态及已记录的上游尝试。首响应是网关首字节，不是模型首 Token；未上报字段为“—”。门户不展示账号池内部标识、原始上游错误或对话正文。无请求标识的历史日志独立显示，入口鉴权等尚未生成用量行的拒绝不在本列表中。
