# 用户门户与管理员

[返回项目首页](../README.md)

用户入口为 `/portal/`，管理入口为 `/admin-ui/`。登录后自动识别身份并跳转；入口是否公开由部署者配置。

## 用户流程

1. 按站点设置注册或使用邀请码，登录后即可创建 Key，**无需先贡献账号**。
2. 从「可用模型」复制调用名，在客户端配置网关地址和 Key。
3. 可选贡献个人账号，账号和 Key 均进入管理员的统一管理页面。
4. 撤回贡献后账号仅本人可用，默认模型权限仍保留。

WorkBuddy、Trae、Qoder 支持个人账号授权，OpenCode 支持个人 Zen / Go Key。只能贡献本人凭据，不能自行认领其他用户或管理员账号。贡献方式见 [渠道接入](providers.md)。

本人 Key 可随时查看和复制；模型页与管理台共用参数展示，流量页提供本人用量及调用详情。

## 模型权限

可用模型由默认开放范围、本人账号能力和管理员额外授权共同决定，全局禁用始终生效。

- **自动模式**：发现有明确免费来源的模型，管理员可额外加入或排除。
- **手工模式**：仅开放管理员选中的模型。
- **跟随 Key**：随当前用户权限变化；**固定 Key**：只使用选定范围，仍需具备当前权限。固定空范围不允许调用。

免费来源只决定默认授权，**不保证实际命中免费账号**。模型开放后沿用渠道原有选号策略，可能消耗收费账号额度。撤回贡献的账号不再提供给其他用户。

## 邀请码

管理员可设置使用次数和有效期，复制邀请链接，编辑、停用或恢复，并查看使用记录。默认一次、7 天，也可明确设置不限次数或永不过期。

次数是成功注册的总人数，不是调用次数。停用、过期或用尽只阻止新注册，不撤销已有用户及 Key。

## 管理员

超级管理员可直接创建管理员或升级已有用户；普通管理员管理普通用户。两者日常管理能力相同，管理员任免和超级管理员交接由超级管理员负责。

临时密码首次登录需修改。身份变更、停用或改密会撤销相关会话。`ADMIN_TOKEN` 保留为管理恢复凭据，不应分发给调用者；管理员身份不会自动扩大其用户 Key 权限。
