# 统一模型路由

[返回项目首页](../README.md)

在「模型 → 统一模型路由」创建一个调用名称，手工选择多个渠道的实际模型并调整顺序。客户端使用这个名称，即可按规则选择渠道，无需改地址或 Key。

## 配置与选择

- 名称可不带前缀，但不能覆盖已有模型、别名、`auto` 或渠道命名空间；保存后不能改名。
- 不按同名自动合并，模型是否适合归为一组由管理员确认。
- 首次按成员顺序选择，成功后保留会话渠道粘性；渠道内部继续使用自身账号策略。
- 请求图片、输出上限及当前权限必须满足实际成员能力。聚合展示使用保守的共同能力，不合并跨渠道价格。

## 故障与权限

尚未开始输出时，可对符合条件的暂时故障尝试其他成员。请求不满足权限或模型要求、以及已经开始输出时，不进行跨渠道重放。

依赖上游续接 ID、加密推理或签名思考的请求需要原渠道状态；无法继续时明确报错，不删除状态强行换渠道。

受限 Key 保存权限时冻结当前成员范围，后续添加成员不会自动扩大该 Key 权限。重新保存模型权限后才授权新成员；门户用户还需具备实际成员的用户权限。

客户端看到统一调用名，日志、消费与续航仍按实际渠道和模型记录。
