# 渠道接入

[返回项目首页](../README.md)

在管理台「账号」页选择渠道并添加凭据。各渠道独立配置，调用模型以模型页或 `/v1/models` 返回的真实 ID 为准。

| 渠道 | 接入方式 | 模型前缀 |
|---|---|---|
| WorkBuddy / CodeBuddy，国内与国际 | 扫码授权、凭据文件导入 | `workbuddy/`，兼容裸 ID |
| Qoder，国内与国际 | 扫码授权、个人 PAT、Windows 本机凭据探测 | `qoder/` |
| OpenCode Zen / Go | 个人 API Key、可选匿名入口 | `opencode/` |
| 国内 Trae IDE / Work-SOLO | 网页授权、JSON 导入、本机登录态导入 | `trae/` |

## WorkBuddy / CodeBuddy

支持多账号、成本与额度感知、会话粘性和故障切换，国内账号提供签到。桌面凭据无法解密时，改用网关扫码授权。

## Qoder

管理员可设置优先激活账号，可重试故障时切换其他符合区域和模型要求的账号。用户贡献不改变管理员激活账号。

Windows 可探测本机已登录凭据；无法解密时改用扫码授权。国内签到和额度刷新可在管理台开启，国际签到尚未支持；PAT 不支持设备令牌额度查询。

## OpenCode

在「编辑配置」中设置 Zen / Go Key 和匿名入口，保存后生效。也可使用 `OPENCODE_CONFIG` 指定配置路径。

官方匿名入口自动使用 `/inference`；自定义端点保持原地址，也可通过 `upstream.anonymous` 单独指定。可选的 `performance.attempt_timeout_seconds` 只限制连接至首次有效流事件的等待，默认不额外限制，流开始后沿用整次请求超时。

不提供账号 OAuth、签到或余额查询。匿名入口是系统资源，用户只能贡献个人 Key。模型页价格为参考价，Go 订阅以实际账单为准。

## Trae

国内 IDE 与 Work/SOLO 分别授权、读取各自模型目录，同一上游用户共用账号归属和余额资源。国际版尚未接入。

远程部署时，浏览器无法直达回调地址可按授权窗口提示手工提交回调。自动签到和额度刷新可在管理台开启；未确认的模型价格不展示为免费。调用采用聊天与调用方工具模式，不启用上游远程 Agent。

用户贡献与撤回规则见 [用户门户](portal.md)，完整迁移使用 [在线备份](operations.md)。

## 模型信息

模型页展示上游确认的上下文、输出上限、图片与工具能力、思考档位和成本信息。WorkBuddy 优惠规则按区域及账号适用范围展示，优惠标签不承诺本次调用免费。

成本系数仅在对应渠道内比较，未知价格显示 `—`，不能视为免费。资源包余额与到期时间在账号页查看，临期额度会提示。
